# Outreach

Context documents and agent skills for outbound to accounting/CPA firms.

## Structure

- `context_docs/` — see `context_docs/README.md` for the index.
  - `network/` — who I know (my LinkedIn connections).
  - `targets/` — who to reach out to (Dream 100 + warm list).
  - `outreach/` — what I've done (connection requests sent, messages sent).
  - `research/` — market research, voice of customer, offers.
- `skills/` — agent skills. Each skill lives in its own directory with a `SKILL.md`.
  - `skills/linkedin-outreach/` — end-to-end LinkedIn outreach campaign playbook.
