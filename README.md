# Outreach

Context documents and agent skills for outbound to accounting/CPA firms.

## Structure

- `context_docs/` — market research, offers, and the Dream 100 account plan.
  - `context_docs/data/` — contact lists (CSV) used as outreach targets.
- `skills/` — agent skills. Each skill lives in its own directory with a `SKILL.md`.
  - `skills/linkedin-outreach/` — end-to-end LinkedIn outreach campaign playbook.
